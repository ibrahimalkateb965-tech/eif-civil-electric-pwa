Engineer Islam Fouda Professional Base V16.14
Based directly on V16.13.

Changes:
1) Added explicit destructive-action permissions: archive/delete for people and teams; delete permissions for work orders, execution evidence, safety, quality, documents and materials.
2) Standard person removal now archives/deactivates the person and preserves historical Work Order links. Permanent deletion is permission-gated.
3) SEC Materials catalogue now distinguishes:
   - PDF Viewer Page: the number to type in the PDF viewer page box.
   - Printed Catalogue Page: the page number printed on the artwork.
4) Verified mapping in the bundled SEC catalogue: PDF viewer page 20 shows printed page 4, so the current catalogue section uses printed page = PDF page - 16.
5) Materials search accepts material data plus either page reference, and material view explains which number to type in the PDF viewer.
