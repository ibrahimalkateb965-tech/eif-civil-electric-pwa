V16.34 — HR Control Center
- HR alerts for Iqama, SEC ID, accreditations and expiring custom data; default 15 days, configurable.
- SEC ID uses expiry date as the operational date; start date removed from the add-person UI.
- Accreditation start is optional; expiry is mandatory when an accreditation is entered.
- Flexible employee additions: custom data, notes, accreditation records.
- HR corners: People/filters, Iqama, Accreditations, Industrial Security/SEC Cards, Alerts.
- Status indicators: green valid, orange expiring soon, red expired, yellow returned with return form.
- SEC card return requires uploaded return form; renewal requires new expiry and card file; history retained.
- Search/filter by person, profession, Iqama, nationality, role.
- Preserves V16.33 permission claims/delegation and V16.32 PDF viewer fixes.
