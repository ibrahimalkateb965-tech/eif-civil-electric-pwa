Engineer Islam Fouda Work Management System — V16.17

Main addition: Hierarchical Access Control.
- Role + Scope + Assignment + Record-level Delegation.
- Engineers can view/download team Work Orders but edit/upload only assigned Work Orders unless delegated.
- Team/department/project manager scopes.
- Super Admin scope.
- Execution/Safety/Materials manager-oriented permission presets.
- Work Order person assignment selector.
- Per-user Access Manager and per-WO delegation/revocation.
- Team Room labels each Work Order as View Only or Edit Allowed.
- Access/delegation audit log data foundation.

Important: local browser demo authentication remains front-end/localStorage based. It is not production server-side security.
